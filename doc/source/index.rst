foliplus
========

A practical Folium extension toolkit built to simplify spatial data visualization
workflows and focus on your data analysis.

.. grid:: 1 2 2 3

   .. grid-card:: 🗺️ MapSearch
      :padding: 2

      Coordinate & address search with Nominatim geocoding.

   .. grid-card:: 🧭 LayerControl
      :padding: 2

      Enhanced layer switcher with drag-and-drop, color layers, SVG icons.

   .. grid-card:: 🖥️ Fullscreen
      :padding: 2

      Fullscreen toggle that hides other controls for a clean view.

   .. grid-card:: 🔥 HeatmapControl
      :padding: 2

      H3 hexbin aggregation heatmap with real-time zoom adaptation.

   .. grid-card:: 📏 MeasureControl
      :padding: 2

      Distance measurement, circle drawing, and GPS locate tools.

   .. grid-card:: 📐 ScaleControl
      :padding: 2

      Scale bar with metric/imperial units and optional zoom label.
