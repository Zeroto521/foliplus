foliplus.MeasureControl#

class foliplus.MeasureControl(*, position: Literal['topleft', 'topright', 'bottomleft', 'bottomright']='bottomright', show_bearing: bool = True, label_show: bool = True, label_collide: bool = True, show_live_coords: bool = True, filter: Annotated[list[str] | None, ~foliplus._config_schema.FieldSpec(ts=object, optional=False, nullable=False, values=None, item=None, dynamic=False, default=<object object at 0x0000018599BA07C0>, note=Declared measurement-type filter: the shared filter AST normalised from the friendly list of type names the argument takes; a persisted user filter wins., shape=None, name=None, config_key=None)] = None, filename: str = 'measurements', export_format: Literal['geojson', 'csv']='geojson', collapse_on_outside: bool = True, zoom_range: Annotated[dict[str, ~typing.Any] | None, ~foliplus._config_schema.FieldSpec(ts=ZoomRange, optional=False, nullable=False, values=None, item=None, dynamic=False, default=<object object at 0x0000018599BA07C0>, note=Declared zoom range: the toolbar is visible only while the map's zoom is inside it; a malformed or unreachable range is treated as undeclared., shape={'min': 'number', 'max': 'number'}, name=ZoomRange, config_key=zoomRange)] = None, locale: str | LocaleConfig | None = None)[source]#

Bases: BaseControl

Measure distances, areas, and circles; place geocoded markers; then edit by dragging nodes.

The modes:

Mode

Finish gesture

Behavior

📍 Locate

Click the toolbar button

Shows coordinates and a reverse-geocoded address; click the popup or the × to delete.

📏 Distance

Double-click / right-click / click the last node

Click to draw a polyline; segment and total distances update in real-time.

🔲 Area

Double-click / right-click / click the first or last node

Click to draw a polygon; the enclosed area and each side’s length are labeled.

⭕ Circle

Second click confirms

First click sets the center; move the mouse to set the radius.

Editing

The pencil toolbar button toggles edit mode:

Situation

Behavior

Click a measurement outside edit mode

Does not reveal its × delete handles.

Enter edit mode while a drawing mode is armed

The drawing mode exits — edit mode and the drawing modes are mutually exclusive.

Click a measurement while another shows × handles

The previous one closes; only one measurement shows handles at a time.

Shortcuts#

Key

Action

Escape

Exit the current measurement mode, or exit edit mode

Parameters#

positionstr, default “bottomright”

One of “topleft”, “topright”, “bottomleft”, “bottomright”.

show_bearingbool, default True

Whether to show the bearing (azimuth, 0°–360° clockwise from north) alongside the distance in segment labels, e.g. 45° | 1.2 km. Only applies to distance mode; area and circle modes always show plain distance.

label_showbool, default True

Whether to show the measurement labels. Hidden labels stay registered (collision and placement state is untouched) — switching back on restores them on their anchors. Overridable at runtime from the layer style drawer.

label_collidebool, default True

Whether to run the label collision detector. When enabled, a label is hidden only when two chips intersect on the y-axis AND overlap at least 75% of the narrower chip’s width on the x-axis, so chips that share a screen column but are stacked vertically (e.g. labels on two near-vertical polygon edges at very different y) stay visible and a light edge graze is left alone. Hiding sweeps labels from strongest to weakest — centroid and radius, then the distance mode’s final total, then plain segments; a tie goes to the wider chip — so the most important label always keeps its anchor. When disabled, every label stays visible on its anchor regardless of overlap. Only affects on-screen layout, never exports (CSV / GeoJSON always read persisted measurements).

show_live_coordsbool, default True

Whether to show a live longitude/latitude readout. While any drawing mode is armed — and again while edit mode is on — a small chip trails the cursor for the whole time, including before the first click, so the coordinate about to be placed or dragged is visible instead of only the ones already placed. It hangs due south of the pointer, the same way the area label sits south of the centroid dot, and is flipped above the pointer near the bottom edge of the map. It disappears as soon as the measurement is finalized: a finished measurement is described by its shape and segment labels, not by a coordinate under the pointer. No coordinate-system conversion is applied — the chip reports the map’s own coordinates as they are, so it stays put under the cursor on GCJ02 / BD09 tile sets.

filterlist[str], optional

Starting filter on the measurement types. See Notes for the declaration shape and the runtime’s handling of unknown names.

filenamestr, default “measurements”

Base filename for exported files (without extension). The format extension is appended automatically: measurements.geojson or measurements.csv.

export_formatstr, default “geojson”

Default export format. One of "geojson" or "csv".

  • "geojson" produces a FeatureCollection where each feature’s properties carries the measurement id, type name, and type-specific fields (address, totalDistance, area, radius, center).

  • "csv" produces one row per measurement with an id column and a wkt column holding the Well-Known-Text geometry.

collapse_on_outsidebool, default True

Whether a press outside the panel collapses it.

zoom_rangedict, optional

Visibility window over the map’s zoom levels: a mapping with min and max (both required integers, min <= max) that keeps the control visible only while the map’s zoom is inside the range. Outside the range the whole toolbar is hidden; it comes back on the next zoom that is inside. A malformed declaration, or one that cannot meet the map’s own zoom range, warns once and is treated as undeclared (the toolbar stays visible). Measurements are never hidden or deleted by this declaration — it gates the toolbar, not the data.

localestr or LocaleConfig, optional

Language code (“en”, “zh”) or a LocaleConfig instance. Defaults to auto-detection, falling back to English.

Examples#

>>> import folium
>>> from foliplus import MeasureControl
>>> m = folium.Map()
>>> MeasureControl().add_to(m)

With a declared starting filter on the measurement types:

>>> import folium
>>> from foliplus import MeasureControl
>>> m = folium.Map()
>>> MeasureControl(filter=["distance", "polygon"]).add_to(m)

Only show the toolbar while the map is between zoom levels 8 and 12:

>>> import folium
>>> from foliplus import MeasureControl
>>> m = folium.Map()
>>> MeasureControl(zoom_range={"min": 8, "max": 12}).add_to(m)

Notes#

Filter declaration

filter is a list of measurement-type names (the min/max mapping form, a min/max mapping, belongs to HeatmapControl):

Key

Type

Required

Meaning

each element

str

yes

A measurement-type name the panel’s filter row offers: distance, polygon, circle, marker.

Situation → behavior

Situation

Behavior

An unknown type name, alone or beside the known ones

Reported once with a warning; the declaration is rejected whole and treated as undeclared — never a partial subset.

An empty list

Reported once with a warning; treated as undeclared.

A mapping (the range branch)

Reported once with a warning; treated as undeclared — range filters belong to HeatmapControl.

User write (the filter row)

Wins from then on; the declaration is a starting condition only.

The filter row’s Clear

Keeps the user’s clear: the declaration does not come back (this session or on reload).

Factory Reset (the toolbar’s CLEAR mode)

Deletes the saved record and re-seeds the declaration (this session and on reload).

Zoom-range declaration

zoom_range={"min": 8, "max": 12} takes the same shape the per-layer foliplus declaration uses:

Key

Type

Required

Meaning

min

int

yes

Lowest zoom at which the toolbar is visible.

max

int

yes

Highest zoom at which the toolbar is visible.

Outside the range the toolbar is hidden, not disabled: an active mode is left alone, and measurements already on the map stay visible. A malformed declaration (missing key, non-int, inverted, unknown key) and a range that cannot intersect the map’s own zoom levels both warn once and are treated as undeclared, so the toolbar never disappears for every map view.
