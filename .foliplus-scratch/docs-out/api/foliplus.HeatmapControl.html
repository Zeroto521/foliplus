Bases: BaseControl

H3 hexbin heatmap with zoom-adaptive resolution and labeled hexagons.

Note

Only markers with a .feature property (GeoJSON / df.explore) are counted. Annotation or label markers without .feature are skipped to avoid double-counting in hexbin aggregation.

Parameters#

positionstr, default “topleft”

One of “topleft”, “topright”, “bottomleft”, “bottomright”.

layerstr, optional

Name of the point layer to select when the map first loads. Matching is by the layer’s folium name (the same text the panel’s Layer row lists); the first match wins. This is a starting selection only: a layer the user picked earlier (persisted in the browser) wins, and the panel still lets the user switch. A name that matches no point layer is ignored with a console warning and the panel falls back to its normal auto-selection (the only point layer is selected automatically).

aggLiteral[“count”, “sum”, “avg”, “min”, “max”], default “count”

Default aggregation method. A filter declaration needs a value aggregation (not "count") — count aggregates by nothing, so a range has no field to bind to and raises (see Notes).

fieldstr, optional

Aggregation field to select when the map first loads. Only a numeric field the layer actually carries is accepted; anything else is ignored with a console warning and the panel falls back to its normal default field (the first numeric field). Like layer, a persisted user choice wins, and a count aggregation does not use the field until the user switches to a value aggregation — a filter declaration with agg="count" is therefore API misuse and raises (see Notes).

filterdict, optional

Starting filter on the aggregation field: a mapping with min and max (the range is bound to field=). See Notes for the declaration shape and the failure modes listed there.

methodLiteral[“jenks”, “quantile”, “equal”, “heads”], default “jenks”

Default classification method.

num_classesint, default 6

Number of classification classes, range 2-9.

color_schemestr, default “Reds”

Default color scheme name. Supports chroma.js / ColorBrewer palettes: Blues, Greens, Reds, Oranges, Purples, YlOrRd, Viridis.

schemeslist[str], default [“Blues”, “Greens”, “Reds”, “Oranges”, “Purples”, “YlOrRd”, “Viridis”]

List of available color scheme names. Can include custom hex values like ["#f00", "#0f0", "#00f"].

border_colorstr, default “#333333”

Hexagon border color.

border_weightfloat, default 1.5

Hexagon border width in canvas units. Must not be negative.

border_opacityfloat, default 0.9

Hexagon border opacity, between 0.0 and 1.0.

fill_opacityfloat, default 0.7

Hexagon fill opacity, between 0.0 and 1.0.

label_showbool, default True

Whether to show the aggregated value as a label at each hex center.

label_colorstr, default “#fff”

Label text color.

label_sizeint, default 11

Label font size (px). Must be positive.

label_formatLiteral[“auto”, “int”, “comma”, “percent”], default “auto”

Number format for hexagon value labels:

  • "auto": locale-native compact notation (en 10K, zh 1.2万); zh values below 1万 render ungrouped (6000). Follows the plugin locale.

  • "int": plain integer with no grouping (6000).

  • "comma": thousands separator (6,000).

  • "percent": fraction × 100 with a % suffix (0.35 → 35%).

"int", "comma", and "percent" are locale-agnostic.

collapse_on_outsidebool, default True

Whether a press outside the panel collapses it.

zoom_rangedict, optional

Visibility window over the map’s zoom levels: a mapping with min and max (both required integers, min <= max) that keeps the control visible only while the map’s zoom is inside the range. Outside the range the whole control is hidden with the shared foliplus-hidden class; it comes back on the next zoom that is inside. A malformed declaration, or one that cannot meet the map’s own zoom range, warns once and is treated as undeclared (the control stays visible) — never as a declaration that hides it everywhere.

localestr or LocaleConfig, optional

Language code (“en”, “zh”) or a LocaleConfig instance. Defaults to auto-detection, falling back to English.

Examples#

>>> import folium
>>> from foliplus import HeatmapControl
>>> m = folium.Map()
>>> HeatmapControl().add_to(m)

With a declared starting filter on the aggregation field:

>>> import folium
>>> from foliplus import HeatmapControl
>>> m = folium.Map()
>>> HeatmapControl(
...     agg="sum", field="score", filter={"min": 10, "max": 50}
... ).add_to(m)

Only show the control while the map is between zoom levels 8 and 12:

>>> import folium
>>> from foliplus import HeatmapControl
>>> m = folium.Map()
>>> HeatmapControl(zoom_range={"min": 8, "max": 12}).add_to(m)

Notes#

Filter declaration

filter is a mapping with min and max (the list form, a list of measurement-type names, belongs to MeasureControl):

Key

Type

Required

Meaning

min / max

number each

yes

Inclusive range on the aggregation field (field=).

Situation → behavior

Situation

Behavior

field key inside filter, no aggregation field (no field=, or agg="count"), or a list of value names

ValueError in the cell that wrote the declaration.

Data-shaped problem (no numeric extent, range outside the data, non-numeric bound)

Reported once with a warning; treated as undeclared — never silently filtered to empty.

User write (the filter row)

Wins from then on; the declaration is a starting condition only.

The filter row’s Clear

Keeps the user’s clear: the declaration does not come back (this session or on reload).

Factory Reset (the panel’s Clear)

Deletes the saved record and re-seeds the declaration (this session and on reload).

Zoom-range declaration

zoom_range={"min": 8, "max": 12} takes the same shape the per-layer foliplus declaration uses:

Key

Type

Required

Meaning

min

int

yes

Lowest zoom at which the control is visible.

max

int

yes

Highest zoom at which the control is visible.

Outside the range the control is hidden, not disabled, so its saved state survives the trip. A malformed declaration (missing key, non-int, inverted, unknown key) and a range that cannot intersect the map’s own zoom levels both warn once and are treated as undeclared: the control stays visible rather than disappearing for every map view.

render(**kwargs: Any) → str[source]#

Inject the shared asset bundle into the figure header exactly once.

The runtime JS, shared CSS, common locale tables, and per-component locale tables are identical for every control, so they are emitted a single time per map (deduplicated by _SHARED_ASSETS_NAME) instead of being repeated in each control’s template. Placing them in <head> also guarantees they load before any control’s body script runs.
