foliplus.LayerControl#

class foliplus.LayerControl(*, position: Literal['topleft', 'topright', 'bottomleft', 'bottomright'] = 'topleft', label_collide: bool = True, collapse_on_outside: bool = False, icon_prefix: Literal['fa-solid', 'fa-regular'] = 'fa-solid', locale: str | LocaleConfig | None = None)[source]#

Bases: BaseControl

Layer panel to organize, inspect, style, and filter map layers.

  • 📐 Geometry-type icons for quick layer identification.

  • 🔀 Drag-and-drop reordering within a section, synced to Leaflet render order.

  • ✅ Multi-select checkboxes with z-index stacking, plus a toggle for all layers in a section.

  • 🎨 Solid-color replacement for base maps.

  • 🎨 Fill by value: color a layer by a numeric field with a classification method, class count, and scheme, use a single fill color, or keep the layer’s own per-feature paint as the read-only original.

  • 🧰 Per-layer style drawer: opacity, zoom range, border, fill, size, and text labels with color, size, number format, and overlap control.

  • 🔎 Filter a layer’s features live: a range on a numeric field, or a set of values on a categorical one, with a kept/total readout and a Clear action.

  • 🗂️ Row actions: rename, attributes, style, filter, and delete or clear with confirmation.

  • 💾 Panel state (order, visibility, folds, names, styles) persists across reloads.

  • 🏷️ Per-layer text labels via foliplus={"label": {"field": ...}} on the layer itself.

  • ⌨️ Keyboard navigation across rows and panels (see the shortcuts table below).

  • 🎯 Zoom the map to a layer’s extent (double-click / ⋮ / Alt+Enter).

Base basemap, color picker, and hidden rows stay quiet: no cursor glow on click or keyboard focus. Their ⋮ “Focus layer” item is disabled (not-allowed cursor) — toggle visibility from the checkbox as usual.

Parameters#

positionstr, default “topleft”

One of “topleft”, “topright”, “bottomleft”, “bottomright”.

label_collidebool, default True

Page-wide default for the per-layer “avoid overlap” setting: when enabled, a layer’s own labels thin themselves out where they overlap. Labels from different layers never avoid each other — the layers are stacked, so an upper layer simply covers the lower one’s. The style panel overrides this per layer.

collapse_on_outsidebool, default False

Whether a press outside the panel collapses it. Off by default: the panel is a working surface read at the same time as the map, and the map’s busiest gesture is drag-pan / click-select. The header close button collapses it explicitly either way.

icon_prefixLiteral[“fa-solid”, “fa-regular”], default “fa-solid”

FontAwesome family class prefix used when the panel renders a glyph picker icon or probes its availability. A layer whose author declared its own prefix (folium.map.Icon(prefix=…)) keeps that prefix; this control-level value is the fallback for every other layer. The control only supports FontAwesome’s solid and regular families (the only two in the glyph table); another family needs its own glyph table and is a separate task.

localestr or LocaleConfig, optional

Language code (“en”, “zh”) or a LocaleConfig instance. Defaults to auto-detection, falling back to English.

Examples#

Mount the panel on a map:

>>> import folium
>>> from foliplus import LayerControl
>>> m = folium.Map()
>>> LayerControl().add_to(m)

A layer may declare its own defaults on the layer itself, in the same foliplus= namespace the fill and label declarations use. Declare a visible zoom range:

>>> import geopandas as gpd
>>> gdf = gpd.read_file("boundaries.geojson")
>>> m = gdf.explore(foliplus={"zoom_range": {"min": 8, "max": 12}})
>>> LayerControl().add_to(m)

Declare per-layer text labels:

>>> gdf.explore(foliplus={"label": {"field": "name", "collide": False}})

Declare a value-based fill that classifies each feature at load:

>>> gdf.explore(foliplus={"fill": {"field": "score", "scheme": "Reds"}})

Notes#

Recognised keys:

Key

Type

Meaning

fill

dict

the layer’s value-based fill (see the fill table below).

label

dict

The layer’s text labels (see the label table below).

zoom_range

dict

The layer’s visible zoom range (see the zoom range table below).

folder

str

The layer’s folder (section group) name; see the note below.

Two layers declaring the same folder name in the same section and role (for example foliplus={"folder": "底图"}) are grouped into one folder — a grouping intent, not a conflict, and it never warns.

Folder names group case-insensitively after whitespace folding, so "Basemap", "basemap" and "BASE MAP" land in one folder. The folder keeps the first spelling it saw (trimmed) as its display name.

A folder keeps its group row after its last layer is removed, so you can still drag more layers into it.

Third-party layers and components:

A third-party or custom folium.map.Layer subclass can declare a folder the same way foliplus layers do, through the same foliplus={"folder": "..."} namespace:

>>> gdf.explore(foliplus={"folder": "底图"})

The same rules apply: a non-string or blank folder warns once and is ignored (the layer stays at the section root), and two layers declaring the same folder name in the same section and role are grouped into one folder. On the JavaScript side, a third-party component can declare its folder through LayerAPI.registerLayer.

The fill declaration keys:

Key

Default

Meaning

field

required — naming one turns value-based fill on

the numeric or categorical feature property to classify

kind

inferred from the layer’s own values

the variant (numeric / category); when omitted the layer’s values are sampled, and a field that mixes value kinds or has no usable value drops it

method

jenks

classification method (jenks / quantile / equal / heads)

classes

6

number of classes, an integer from 2 to 9 (the panel’s maximum)

scheme

Viridis (Set3 for a category variant)

palette name (the style panel’s own candidates)

How a fill declaration is resolved:

Condition

Behaviour

User stored mode

The row shows the stored mode; it always wins.

Valid declaration

The declared ramp classifies each feature by field at load (it does not flatten the layer to a single color); the row opens on it and Reset returns to it.

No declaration

The row shows the detected per-feature state, else the built-in fallback.

Invalid declaration

Degrades key by key (each rejected key warns once, the rest survives); a declaration without a usable field drops whole and falls back to the per-feature paint / built-in.

Value-based fill needs an areal geometry. Polygons (Polygon, MultiPolygon, Rectangle) and circles (Circle, CircleMarker) repaint by value; a Polyline takes a stroke colour instead, so value-based stroke is a known gap; and a marker is an icon, which has no fill to repaint.

The label declaration keys:

Key

Type

Required

Meaning

int

How a zoom_range declaration is resolved:

Condition

Behaviour

User stored range

The row shows the stored range; it always wins.

Valid declaration

The row opens on it and Reset returns to it.

No declaration

The row opens on the map’s own range.

Declared range cannot meet the map’s zoom levels

Treated as undeclared: the layer stays visible at every level, the degradation warns once, and the row stays editable (it shows the stored value, else the map’s range).

Malformed declaration (missing key, non-int, inverted, unknown key)

Warns once and is treated as undeclared; never hides the layer.

A declaration is a default, never a rewrite: it does not modify the layer’s own data.

Inject the shared asset bundle into the figure header exactly once.
